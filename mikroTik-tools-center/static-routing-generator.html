مولد التوجيه الثابت (Static Routing)

توليد سكربتات RouterOS لتوجيه يوتيوب، تيك توك، فيسبوك، واتساب، وغيرها الكثير عبر خط ISP محدد

باختصار: هذه الأداة تجعل نوعًا معينًا من الترافيك (مثل يوتيوب أو واتساب) يمر دائمًا عبر خط إنترنت محدد بدل توزيعه عشوائيًا بين خطوطك، وذلك بتوليد سكربت جاهز تنسخه وتنفذه في جهاز الميكروتك على خطوتين.

إعدادات السكربت

اختر التطبيق أو الموقع الذي تريد أن يمر بياناته عبر خط إنترنت محدد دون غيره.

إصدار نظام التشغيل في جهازك (تجده في Winbox أعلى الشاشة). الأوامر تختلف قليلًا بين v6 وv7.

طريقة تحديد هوية الموقع: TLS-HOST تعتمد على اسم النطاق (أدق وأنسب للمواقع المشفّرة HTTPS)، وCONTENT تفحص محتوى الحزمة. اختر TLS-HOST إن لم تكن متأكدًا.

عنوان IP الخاص بالخط (ISP) الذي تريد أن يمر عبره هذا التطبيق تحديدًا — وليس عنوان جهاز المستخدم.

اسم مميّز تختاره أنت لتمييز هذا الخط داخل إعدادات الراوتر (مثال: To-ISP-1 أو Line-A). استخدم نفس الاسم إن كنت توجّه عدة خدمات على نفس الخط.

اضبط الخيارات أعلاه ثم اضغط على زر "توليد السكربت" لتظهر لك أوامر الخطوتين هنا.

الخطوة 1 — تحميل قائمة عناوين IP للخدمة

هذا الأمر يحمّل ملفًا جاهزًا يحتوي على عناوين IP الخاصة بالخدمة المختارة. انسخه والصقه في نافذة Terminal داخل Winbox، ثم اضغط Enter.

## STEP 1 - Copy Paste to Terminal
/file remove "Mikrotik-Youtube.rsc"
/tool fetch url="https://buananet.com/mikrotik-routeros-rsc/tls-host/Mikrotik-Youtube.rsc" dst-path="Mikrotik-Youtube.rsc"
الخطوة 2 — تفعيل التوجيه فعليًا

هذا الأمر يستورد قائمة العناوين التي حمّلتها في الخطوة الأولى، وينشئ قاعدة التوجيه والقاعدة التي تربط الخدمة بخط الإنترنت المحدد. الصقه بعد نجاح الخطوة الأولى مباشرة.

## STEP 2 - Copy Paste to Terminal
/import file-name="Mikrotik-Youtube.rsc"
/file remove "Mikrotik-Youtube.rsc"
/ip route add check-gateway=ping distance=1 gateway="0.0.0.0" routing-mark="To-ISP-1" comment="Route by MusaleM"
 /routing table add name="To-ISP-1" fib comment="Route by MusaleM"
/ip route add check-gateway=ping distance=1 gateway="0.0.0.0" routing-table="To-ISP-1" comment="Route by MusaleM"
 /ip firewall address-list add address=192.168.0.0/16 list=LOCAL-IP comment="LOCAL IP - MusaleM"
/ip firewall address-list add address=172.16.0.0/12 list=LOCAL-IP comment="LOCAL IP - MusaleM"
/ip firewall address-list add address=10.0.0.0/8 list=LOCAL-IP comment="LOCAL IP - MusaleM"
/ip firewall mangle remove [find comment="Youtube - MusaleM"]
/ip firewall mangle add action=mark-routing chain=prerouting src-address-list=LOCAL-IP dst-address-list="Mikrotik-Youtube" new-routing-mark="To-ISP-1" passthrough=no place-before=*0 comment="Youtube - MusaleM"
